Mod Hub by VirtuOzZ — менеджер модов GTA V (Legacy и Enhanced). Версия 0.4 beta.

ВАЖНО: Mod Hub проверялся только на чистой игре. Как он поведёт себя, если в GTA V
или GTA V Enhanced уже установлены моды (вручную, через OpenIV и т. п.), ещё не
тестировалось. Перед использованием сделайте резервную копию игры.

УСТАНОВКА
1. Распакуйте архив прямо в корень системного диска C:\ — получится
   C:\Mod Hub by VirtuOzZ. Это и есть установленная программа.
   Не распаковывайте в папку игры, в Program Files (туда нельзя писать без прав
   администратора) и в папки, которые синхронизирует OneDrive (Рабочий стол,
   Документы), — туда попадут ключи игры и кэш встроенного браузера.
2. Запустите «Mod Hub.exe». Устанавливать .NET не нужно — всё уже внутри.
   Если Windows покажет «Система Windows защитила ваш компьютер»:
   «Подробнее» → «Выполнить в любом случае» (сборка не подписана).
3. Игра находится автоматически (Rockstar Launcher, Steam, Epic). Если нет —
   «Указать папку игры вручную…».
4. На странице «Установка мода» есть «База для моддинга»: Script Hook V,
   загрузчик папки mods и ScriptHookVDotNet ставятся одной кнопкой.

ЧТО ГДЕ ЛЕЖИТ
Mod Hub ничего не устанавливает в Windows и не пишет в AppData.
  Mod Hub by VirtuOzZ\
    Mod Hub.exe      — запуск программы
    README RU.txt    — этот файл (README EN.txt — то же по-английски)
    Settings.json    — настройки (появится после первого запуска)
    Languages\       — свои переводы интерфейса
    Program\         — файлы программы, трогать не нужно
    Data\            — ключи игры, кэш, встроенный браузер, загрузки, временные файлы,
                       отчёты об ошибках (Data\Logs)
Рядом с игрой, на том же диске, Mod Hub создаёт папку ModHub
(например D:\ModHub\Legacy или D:\ModHub\Enhanced): журнал установок, отключённые
моды, копии для отмены. Она должна быть на диске игры, чтобы установка и отмена
проходили мгновенно. Там же по умолчанию лежат резервные копии (D:\ModHub\Backups).
В реестр Windows программа пишет только если вы сами включите открытие .oiv-файлов
двойным щелчком (Настройки).

УДАЛЕНИЕ
Кнопка «Удалить Mod Hub…» в настройках пока не работает. Чтобы удалить Mod Hub,
просто удалите его папку:
1. Если хотите вернуть игру к исходному состоянию — в Mod Hub нажмите
   «Вернуть ванильную игру» (или отмените установки в «История и отмена»).
2. Если включали открытие .oiv двойным щелчком — выключите его в настройках.
3. Удалите папку «Mod Hub by VirtuOzZ».
4. Удалите папку ModHub в корне диска игры (журнал, отключённые моды и резервные копии).
   Делайте это только после шага 1: иначе отменить установленные моды будет нечем.

Нужен интернет: при первой установке скачиваются Script Hook V (dev-c.com),
ScriptHookVDotNet (GitHub) и файл ключей magic.dat из проекта CodeWalker (GitHub).
Перед установкой модов закройте игру. Запись в папку игры требует подтверждения
прав администратора (UAC).

Нашли ошибку — пришлите скриншот и что делали перед этим. Если Mod Hub показал
сообщение о непредвиденной ошибке, приложите файл из папки Data\Logs.
