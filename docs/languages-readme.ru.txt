Папка Languages — свои переводы интерфейса Mod Hub.

Русский, английский и украинский уже встроены в программу, класть их сюда не нужно.
Сюда кладутся дополнительные переводы — файлы .json.

Как сделать свой перевод:
1. Настройки → Язык интерфейса → «Создать шаблон». Сохраните JSON-файл:
   в нём все строки программы.
2. Поменяйте в файле id (свой, без префикса official.), culture (код языка),
   displayName (название в списке), author и version.
3. Переведите значения в strings. Ключи и параметры {0}, {1} не меняйте.
   Сохраните файл в кодировке UTF-8.
4. Положите файл в эту папку, нажмите «Обновить список» и выберите свой перевод.

Непереведённые строки берутся из встроенного перевода того же языка, затем из русского.
